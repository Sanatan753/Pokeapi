# Pokémon API Fun Project 🎮

This is a small fun project built using the **Pokémon API** to explore how APIs work and how data can be fetched dynamically in a website.
You can check the website through this link (https://sanatan753.github.io/Pokeapi/)

The website includes a **Randomize** button that fetches random Pokémon data and displays:

* Pokémon name
* Height
* One ability
* Normal sprite image
* Shiny sprite image

## Purpose of the Project

The main goal of this project was to:

* Learn how to work with APIs
* Understand fetching and handling JSON data
* Practice basic frontend development
* Build something small and fun while learning

This is not meant to be a large-scale application — just a beginner-friendly experimental project made for learning and exploring API integration.

## API Used

This project uses the amazing [PokéAPI](https://pokeapi.co/)

## Features

* Random Pokémon generator
* Fetches live data from the API
* Displays normal and shiny Pokémon variants
* Simple and lightweight UI

* Fetch API
